> ⚠️ 本练习需要 `/dev/video0` 挂着 USB 摄像头（B11 用同一款：640×480 MJPG@120）。
> 没有摄像头时先跳过，设备就绪后补做。

---

## 故障 · 相机掉一半（实测帧率只有标称的一半）

- **坏版本**：`docs/teaching/fault-injection/step4-01-相机掉一半/`
- **症状描述**：程序把相机设成 **640×480 MJPG@120fps**，连续采集 600 帧并统计。
  结果帧率**稳定在 ~62 fps**，恰好是标称的一半多一点点——**每两帧丢一帧**。
  而同一个相机用 `cam_probe`（工程工具）能跑到 **~109 fps**。
  所有参数（格式/分辨率/fps）打印出来都对，就是快不起来。
- **你的目标**：定位根因（一句话）+ 修复 + 让统计帧率回到 **≥100 fps**。

### 板上构建命令

```bash
ssh board
cd ~/myproj/docs/teaching/fault-injection/step4-01-相机掉一半
cmake -B build -S . && cmake --build build -j4
./build/camfps /dev/video0
```
