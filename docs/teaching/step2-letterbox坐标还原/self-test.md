## 一、复述题

1. 口述 letterbox 正向四步（含公式），并说出为什么 scale 取 **min** 而不是 max。
2. 口述反向还原两步（公式），说明「先减 pad 再除 scale」的顺序为什么不能反。
3. 解释「快路径」（640×480 实际场景）为什么能跳过 resize，省下多少时间。
4. 说出漏调 `vb_to_original` 的两个特征：**不报错** + **恒定比例 1/scale**。

## 二、追问链（每题连答 3 层以上）

**链 A（几何）**
> Q: 为什么 letterbox 而不是直接 resize 到 640×640？ → 直接拉伸会怎样？ →
> 对训练/推理分布有什么影响？ → 为什么球不能因此变形？（§6 I 失败的强压实验：球变椭圆→0 检出）

**链 B（坐标的旅程）**
> Q: 球心从模型输出走到串口，一共经过几套坐标系？ → 每套之间是谁负责变换？ →
> 如果漏一环，错误以什么形态出现（恒定比例？固定偏移？） → 为什么"恒定比例"是最难发现的？
