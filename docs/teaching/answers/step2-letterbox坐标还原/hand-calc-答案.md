# step2 · 手算答案（对照 `step2-letterbox坐标还原/hand-calc.md`）

## 题 1

- sw = 640/720 = 0.8889，sh = 640/1280 = 0.5 → **scale = min = 0.5**
- new_w = (int)(720×0.5) = 360，new_h = (int)(1280×0.5) = 640
- dw = 640−360 = 280，dh = 640−640 = 0 → left = right = **140**，top = bottom = **0**

与实测 (140,140,0,0) **完全一致** ✅（00 §6 D）

## 题 2

- (300,200)：x=(300−140)/0.5 = **320**；y=(200−0)/0.5 = **400**
- (500,600)：x=(500−140)/0.5 = **720**；y=600/0.5 = **1200**

## 题 3

1. scale = 640/1706 = **0.375147…**；new_h = (int)(1279 × 0.375147) = (int)479.81 = **479**
2. dh = 640−479 = 161 → top = 161/2 = **80**，bottom = 161−80 = **81**
   实测是 (0,0,80,81) —— **完全一致**。
3. 1px 的成因：`(int)` 对浮点乘积做**截断**（1279×0.375147 的精确值在 479.8~480.0 边缘），
   使 new_h 比"理想 640"少 1 → 下边多 1 像素。**属于预期内**（B7-0 已确认不影响正确性）。

## 题 4

$1 / 0.375147 = 2.6656… \approx \mathbf{2.666}$。

为什么恒定：漏还原时检测值停留在**模型坐标系**；vb2 的 pads 左右为 0（纯缩放无平移），
模型坐标 = 原图坐标 × scale → 比值恒为 **1/scale**，与目标在画面哪儿无关。**这就是最隐蔽的静默错误。**

## 题 5

漏减 `pads.top`：$y_{wrong} = y/1 = y$，正确 $y_{correct} = y-80$ → 偏差恒为 **+80 px**（下移）。

在 480 高的图上，80 px ≈ 画面高度的 **1/6** —— 框会明显偏下，与球完全错位（但形状、大小都对）。
