## 📌 给 AI 的 30 秒上下文（先读这一段）

### 工程是什么
RK3588 上的 **YOLOv5 多线程 NPU 推理工程**（C++14 / CMake），最终目标是做**实时目标跟踪 + 串口下发偏差给下位机**。

### 工作模式（很重要）
```
PC(Windows) 是唯一真源 → git push → 板子裸仓库 ~/myproj.git → 板子 ~/myproj (只读) 编译运行
```
- **只在 PC 上编辑代码**，用 `tools\sync.ps1` 一键同步
- **板子上绝不编辑、绝不 commit**，只 `git pull --ff-only`
- 编辑用 **VS Code 本地模式**，不是 Remote-SSH

### 环境事实
| 项 | 值 |
|---|---|
| 开发板 | Orange Pi 5（RK3588S），IP `192.168.3.226`，SSH 别名 `board` |
| 板子系统 | Ubuntu 20.04.6 focal, aarch64 |
| 工具链 | CMake **3.16.3**（apt 版）、GCC/G++ 9.4.0、OpenCV 4.2.0 |
| NPU | rknpu 驱动 0.9.8，通过 **DRM** 暴露（查 `ls /dev/dri/`，**没有** `/dev/rknpu`） |
| 其他设备 | `/dev/rga` ✅、`/dev/ttyS4` ✅、**无摄像头** ⚠️ |

### 项目路径
| 位置 | 路径 |
|---|---|
| PC 工程（真源） | `E:\desk\学习\C++\mytest\new` |
| PC 一键脚本 | `new\tools\sync.ps1` |
| 板子工程 | `~/myproj` |
| 板子裸仓库 | `~/myproj.git` |

### 用户偏好（协作方式）
- 要**一步一步**教：先讲原理 → 再给改动 → 最后给验证方法，**一次只推进一步**
- 用户倾向**自己手写代码**，会撤销 AI 的大段批量修改 → 改动要小而可解释
- 中文交流
- 用户会要求"重新查看文件" → **每次动手前必须读磁盘上的真实内容**（IDE 附件常是缓存）

### 硬性约定（不要改）
| 约定 | 原因 |
|---|---|
| `cmake_minimum_required(VERSION 3.16)` 不能再提高 | 板子上 apt 的 cmake 只有 3.16.3 |
| `CMAKE_INSTALL_RPATH` 必须是 `$ORIGIN/lib` | 绝对路径换目录就失效；相对 CWD 的 `lib` 必须 `cd` 才能跑 |
| `install(DIRECTORY model ...)` **不能加结尾斜杠** | 加了会丢 `model/` 这一层，而 `postprocess.cc` 硬编码了 `./model/coco_80_labels_list.txt` |
| `CMAKE_BUILD_TYPE` 必须有默认值 | 为空时所有 `*_FLAGS_<CONFIG>` 失效，编译出来是 `-O0` |
| OpenCV 组件按"符号所在的库"选 | `highgui.hpp` 会间接 include `videoio.hpp`，容易"编译过、链接炸" |
