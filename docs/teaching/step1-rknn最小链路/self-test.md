## 二、追问链（每题连答 3 层以上；不翻资料）

**链 A（生命周期）**
> Q: rknn_init 之后 ctx 里有模型吗？ → 那 model_data 什么时候能 free？ →
> 析构顺序为什么是 destroy → free → free？ → 如果先 free 再 destroy 会怎样？

**链 B（一帧数据的旅程）**
> Q: 像素在哪几块内存里存在过？（cv::Mat → inputs.buf → 驱动/NPU → outputs 缓冲 → 反量化）→
> 哪几站是"拷贝"、哪几站是"零拷贝"？ → 量化发生在哪一站？ → 漏 release 泄漏的是哪一站的资源？

## 三、变式题

**变式 1**：跑 `--fast` 全速模式时，`inputs_set` 从 0.105 ms 变成 0.3 ms——第一反应查什么？

**变式 2**：换了一个新模型，`io_num.n_output` 打印为 **9**。程序在哪个循环会出问题？怎么防？

**变式 3**：日志显示 `sdk version: 1.6.0  driver version: 0.8.2`，然后 `rknn_init` 失败返回 `-1`。
你的三步排查顺序是什么？
