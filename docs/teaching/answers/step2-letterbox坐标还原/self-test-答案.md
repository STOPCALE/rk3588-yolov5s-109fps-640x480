# step2 · 自测答案（对照 `step2-letterbox坐标还原/self-test.md`）

## 一、复述题要点

1. 正向四步：scale=min(640/W,640/H) → new_w/h=W/H×scale → dw/dh 平分（left=dw/2）→ copyMakeBorder。
   取 min 的原因：**保证整个画面装得下**（取 max 会把一边裁掉）。
2. 反向两步：x=(x−pads.left)/scale（y 同理）。顺序不能反：pad 是"原图尺度下"的量，
   必须先减掉**原图尺度的补边**，最后才折算缩放。
3. 快路径：尺寸+通道吻合且内存连续 → 直接引用原图 buf（pads=0、scale=1），跳过 resize；
   实测 0.11 ms vs 大图 5.15~6.3 ms（00 §6 D）。
4. 漏还原：不报错、静默；恒定比例 1/scale（vb2 → 2.666）。

## 二、追问链（闭合点）

- 链 A：直接拉伸 → 纵横比失真（圆球变椭圆）→ 与模型训练分布（letterbox 居中补边）不一致 →
  检测退化。**实证**：§6 I 把 720×1280 竖图强压成横屏 → 球变 19.6×8.25 椭圆 → **检出 0**。
- 链 B：三套坐标——模型系 → 原图系（vb_to_original）→ 串口系（相对图像中心的 dx,dy，
  如 `352.3−320=+32`）。漏"还原"→恒定比例；漏"相对中心"→固定偏移 ±(320,240)。
  恒定比例最难发现：形状、相对关系、目视"有检测"全正常，只有**绝对数值**悄悄错。

## 三、变式题参考答案

**变式 1**：scale 不变 0.375147；new_h = (int)(1278×0.375147) = (int)479.44 = 479 → dh=161 →
top=80、bottom=81（与 vb2 恰好同为 80/81）。

**变式 2**：框整体缩到 1/2.666 → **漏调 `vb_to_original`**（或还原没生效）。

**变式 3**：先除后减 = 400/0.5 − 140 = 800−140 = **660**；正确 = (400−140)/0.5 = **520**。
偏差 = pads.left × (1/scale − 1) = 140×(2−1) = **+140 px**。
