## 二、追问链（连追 5 层"为什么"）

**链 A（性能设计）**
> Q: 为什么要做整数预筛？ → 为什么整数比较能自动向量化而浮点解码不能？ →
> 为什么 151,200 字节放得进 L2 很重要？ → 如果输出是 fp32 而非 int8，预筛方案还成立吗？ →
> 什么时候"预筛 + 解码"的分层会失效？

**链 B（正确性）**
> Q: 为什么 stride 要反推而不写死？ → 如果换了 480 模型但代码写死 8/16/32 会怎样报错吗？ →
> 为什么 anchor 是"像素单位"而不归一化？ → 如果训练时开了 autoanchor，沿用标准值会是什么症状？ →
> 怎么用一个快速实验判断 anchor 是否匹配？（提示：B7-1 的 r 对照法）
