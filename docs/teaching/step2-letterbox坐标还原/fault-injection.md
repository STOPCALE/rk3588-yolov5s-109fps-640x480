## 故障 · 红圈不套球（框系统性偏移）

- **坏版本**：`docs/teaching/fault-injection/step2-01-红圈不套球/`
- **症状描述**：程序对输入图做 letterbox，再拿一个**已知正确位置**的框（按正向公式算出的模型坐标），
  用"还原函数"把它转回原图并画出来。结果：
  - 绿圈（正确位置，用原图坐标直接画）**在画面中央**；
  - **红圈（"还原后"的位置）整体向下偏移**——程序打印的 `delta_y` 恒为 **+80**（640×480 输入时）；
  - 换 720×1280 的图，偏移量变成别的常数——**偏移随图尺寸按固定规律变化**。
- **你的目标**：定位根因（一句话）+ 修复还原函数 + 让 `delta = 0`（红圈与绿圈完全重合）。

### 板上构建命令

```bash
ssh board
cd ~/myproj/docs/teaching/fault-injection/step2-01-红圈不套球
cmake -B build -S . && cmake --build build -j4
./build/restore ~/testimg/vb640.jpg out.png     # 或任意一张图
```

把 `out.png` 取回 PC 看（`scp board:.../out.png 本地`），同时看程序打印的坐标对比。
